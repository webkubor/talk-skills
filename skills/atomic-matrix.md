# 5D 原子表达组合矩阵速查（Atomic Expression Matrix）

> **设计哲学**：拒绝粗颗粒度的空洞流程。将表达拆解为五个维度的原子积木，创作者与 Agent 可以自由按需拼装，生成无限种极具「人味」、契合特定平台心智的高质量内容。

```
                    【5D 原子拼装公式】

 [ 👤 谁在说 (Persona) ]
        ×
 [ 🌐 在哪说 (Platform) ]
        ×
 [ 🎯 为什么说 (Scenario / Intent) ]
        ×
 [ 🎨 口吻与温度 (Tone & Stance) ]
        ×
 [ 🪝 第一句接待/开场 (Opener) ]
        =
 【 独一无二、毫无 AI 假人味的精准表达 】
```

---

## 一、五个维度的原子积木清单

### 1. 👤 角色原型原子（Persona Archetypes）
- `P1·独立开发者/工具极客`：真实自曝踩坑、极客手搓精神、不卖焦虑、以实测与代码事实说话。
- `P2·生活观察/萌宠记录者`：平视温情、闺蜜唠嗑、分享真实翻车与蠢萌、充满生活碎碎念。
- `P3·东方美学/古典创作者`：克制留白、画面感强、注重微观感官通感、私人夜读视角。
- `P4·同级评审/开源协作者`：对事不对人、自曝先行、将问题归因于客观情境、尊重对方劳动。
- `P5·社群主理/服务接待人`：情绪接纳先行、确定性步骤拆解、闭环交付时间承诺、不推诿。

### 2. 🌐 平台场域原子（Platform & Medium）
- `M1·网易云音乐`：私人深夜感、回忆共鸣、器物通感、30% 留白轻问。
- `M2·小红书`：大情绪开场击穿、3:4 滑滑卡轮播图呼应、生活口语、低门槛互动单选题、≤10个标签。
- `M3·Twitter / X`：两行打碎认知、反常识金句、痛点对比、Thread 1 挂一行命令或仓库闭环。
- `M4·GitHub / 技术社区`：环境上下文全披露、预期行为 vs 实际行为、最小可复现步骤（MRE）。
- `M5·微信公众号`：深度长文沉浸契约、工具结论型表格/架构卡、反思型成长长文。

### 3. 🎯 场景意图原子（Scenarios & Intents）
- `S1·新作品/工具首次发布`（如何不自嗨地介绍新产物）
- `S2·遭遇严重翻车/负面吐槽`（如何不辩解地承接并化危为机）
- `S3·日常摸鱼/情绪共鸣`（如何真实记录生活琐碎并打动同类）
- `S4·深度技术/认知复盘`（如何不卖弄地总结一次重构或教训）
- `S5·私信催单/报错求助接待`（如何在 3 句话内给对方安全感）

### 4. 🎨 口吻调性原子（Tone & Stance）
- `T1·粗粝真实`：说人话、带轻微自嘲与口癖、允许不完美的口语节奏。
- `T2·克制留白`：少用形容词、写客观物象与动作、话说七分。
- `T3·热烈唠嗑`：短句、emoji、高频心理叹词（“救命”、“笑死”）。
- `T4·严谨平视`：冷静客观、承认边界、给出推翻的条件。

## 二、高频实战组合配方库（Ready-to-use Recipes）

### 🧪 配方 01：【古典音乐新曲发布】
- **组合参数**：`P3 (美学创作者)` × `M1 (网易云音乐)` × `S1 (新作品发布)` × `T2 (克制留白)`
- **生成产物**：
  > “录到第 2 分 14 秒那声笛音破开的时候，录音棚外正好下起了暴雨。调音师摘下耳机愣了两秒说：‘这段别修了，留着那声换气吧。’ 有些旋律不是写出来的，是风雪自己在撞门。今晚关了灯，留给失眠的人。”

### 🧪 配方 02：【周六打工人宠物生活】
- **组合参数**：`P2 (萌宠生活者)` × `M2 (小红书)` × `S3 (日常摸鱼)` × `T3 (热烈唠嗑)`
- **生成产物**：
  > “救命！我家逆子今天彻底不装了……一大早直接摊成一块猫饼 🫠 拖不动，根本拖不动！脸颊肉贴着地板挤出三层肉褶，眼神写满‘谁叫我我跟谁急’。  
  > 测测你今天的周末电量：A. 100% 狂欢出游  B. 0% 跟我一样变成液体猫饼。留个爪印给宝子们～  
  > #猫咪日常 #治愈系 #周末日常 #表情包”

### 🧪 配方 03：【开源工具突破发布】
- **组合参数**：`P1 (极客开发者)` × `M3 (Twitter/X)` × `S1 (新工具发布)` × `T1 (粗粝真实)`
- **生成产物**：
  > “被官方文档的‘开箱即用’折磨了整整三天，排了 4 个隐蔽的内存泄漏坑。  
  > 源码拆完后发现：根本不需要搞什么复杂的全局守护进程，10 行原生的管道协议就能搞定。  
  > 实测冷启动从 850ms 压到 19ms。零常驻、单文件二进制。  
  > ⬇️ Thread #1 附一行安装脚本与开源仓库地址。”

### 🧪 配方 04：【面对用户质疑产品的尖锐反馈】
- **组合参数**：`P5 (主理人接待)` × `M4 (GitHub/私信)` × `S2 (客诉承接)` × `T4 (严谨平视)`
- **生成产物**：
  > “说得挺狠，但我刚复现了你的调用链路，确实切中了我们最开始设计时的偷懒点。  
  > 目前这套架构在瞬时吞吐暴涨时确实会排队卡死，这是必须还的技术债。现在有两种解法：方案 A 明天打临时热补丁，方案 B 下周重构连接池。如果是你的线上业务，你更希望先上哪一个？”

## 三、如何向 Agent 委派任务（调用示例）

用户在委派 Agent 撰写文案时，只需给出一行参数组合，Agent 即可精准吐出无 AI 假人味的文字：

```bash
# 示例：让 Agent 组合出一条小红书技术辟坑文案
talk-skills compose \
  --persona P1 \
  --platform M2 \
  --scenario S4 \
  --topic "为什么我不建议新人第一天就学重型框架"
```
