# 全平台表达风格与媒介心智规范

同一个事实，在不同媒介与平台上必须用完全不同的「心理货币」来结算。**脱离平台心智的表达，无论逻辑多严密，都是无效噪点。**

本分册定义**抽象的媒介心智与赛道原型**，完全不硬编码任何私有业务实体，任何创作者、开发者与 AI Agent 均可按需自由组合套用。

```
用户打开平台时的心理预设决定了内容的生死线：
├─ 🎵 网易云音乐   → 卸下理性防线 · 寻找情绪同温层 · 私人记忆投射
├─ 📕 小红书       → 大拇指高速刷动 · 寻找即刻多巴胺或具体生活解法
├─ 🐦 Twitter (X)  → 极度厌恶铺垫 · 崇尚反直觉认知 · 工具与落地效率
├─ 🐙 GitHub       → 追求确定性 · 极度珍惜时间成本 · 严谨排障
└─ 📱 微信公众号   → 沉浸式深度阅读 · 寻找思考认同或完整工具结论
```

## 一、🎵 网易云音乐（情怀 · 通感 · 私人夜读）

### 1. 核心受众心理机制
- **投射效应（Projection Effect）**：读者不是在听创作者的自述，他们是在文字里**认领自己未被说出的遗憾、孤独与回忆**。
- **感官通感（Synesthesia）**：将旋律、器乐转化为具体的触觉、温度、光影与味道。

### 2. 表达法则
- **白描重于抒情**：写出具体的时间、具体的物件、微小的身体反应，坚决不堆砌「太感动了」「太好听了」这类空洞形容词。
- **克制与留白**：话不说满，留出 30% 让听众的心事住进来。
- **平视私语**：不是台上歌手对台下观众喊话，而是深夜长椅上两个陌生人的并肩小声说话。

### 3. 经典结构范式
```text
【微观镜头接入】具体的时间/天气/声音细节（如：暴雨夜、末班车、器乐破空的一瞬）
  ↓
【通感与情绪投射】身体感官体验（如：后颈发凉、突然想按暂停、喉咙发紧）
  ↓
【留白轻问】把话筒递给读者（如：“今晚你那里下雨了吗？”、“你有多久没在天黑前下班了？”）
```

### 4. 正反案例对比（以传统美学/器乐创作者原型为例）
- ❌ **公关腔推销（自嗨反动）**：
  > “我的新单曲《寒江雪》全网上线啦！融入了传统笛箫与现代氛围音效，制作历时半年，特别走心！大家快去点赞收藏加入歌单，支持独立音乐人！”  
  > *（致命缺陷：典型的自嗨推销。读者心想「你辛苦跟我有什么关系」，划走率 99%。）*
- ✅ **情怀通感体（共鸣留白）**：
  > “录到第 2 分 14 秒那声笛音破开的时候，录音棚外正好下起了暴雨。调音师摘下耳机愣了两秒说：‘这段别修了，留着那声换气吧。’ 有些旋律不是写出来的，是风雪自己在撞门。今晚关了灯，留给失眠的人。”  
  > *（心理机制：具体的棚内细节 + 真实的未修瑕疵 + 关灯夜读投射，评论区必引爆故事共鸣。）*

## 二、📕 小红书（大情绪击穿 · 生活唠嗑体 · 3:4 视觉共振）

### 1. 核心受众心理机制
- **即刻多巴胺与视觉锚定**：双列瀑布流下，读者判定点不点开只有 0.3 秒。封面决定生死，前三行决定留存。
- **平视同盟感（Peer-bonding）**：读者极度反感“权威居高临下指导”，极度偏爱“养宠/搞钱/变美的同温层真实翻车与自曝”。

### 2. 表达法则
- **大情绪开场（击穿心理防线）**：善用口语短句、心理叹词（“救命！”“真服了！”“当场愣住”）。
- **画册呼应（滑滑卡体验）**：正文必须逐张呼应 P1~P5 的图片内容，引导用户右滑翻图，拉升停留时长。
- **互动埋钩（低门槛单选）**：末尾必须设置具象化互动选项（如：“你今天电量是 A 还是 B？”），让评论门槛降到极低。
- **标签红线**：话题**严格控制在 10 个以内**，前 3 个必须是垂类精准大词。

### 3. 经典结构范式
```text
【首行大情绪痛点】真实翻车/反差自曝/情绪爆发句
  ↓
【场景逐图还原】P1~P4 的动作细节，搭配活泼 emoji 与短句排版
  ↓
【情绪升华/实用总结】给读者一个拥抱或一条避坑经验
  ↓
【低门槛单选题】设置评论区参与选项（A/B/C）
  ↓
【精准标签区】≤10 个话题，拒绝泛滥乱挂
```

### 4. 正反案例对比（以萌宠生活记录者原型为例）
- ❌ **动物图鉴说明文**：
  > “英短猫性格温顺，喜欢在温暖的地方休息。今天周六天气很好，猫猫在阳光下睡得很香，大家周末愉快。”  
  > *（致命缺陷：没有情绪张力，读者毫无点赞和互动欲望。）*
- ✅ **生活唠嗑爆款体**：
  > “救命！我家逆子今天彻底不装了……一大早直接摊成一块猫饼 🫠 拖不动，根本拖不动！脸颊肉贴着地板挤出三层肉褶，眼神写满‘谁叫我我跟谁急’。  
  > P1：彻底融化的液态猫饼  
  > P2：非要硬塞进迷你纸箱（胖肉全溢出来了）  
  > 测测你今天的周末电量：A. 100% 狂欢  B. 0% 跟我一样变成液体猫饼  
  > #猫咪日常 #治愈系 #周末日常 #表情包”

## 三、🐦 Twitter / X（独立极客 · 反常识 · 短平快）

### 1. 核心受众心理机制
- **信息密度崇拜（Density Over Form）**：X 用户大多是开发者、创业者与极客，极度厌恶客套，追求第一行获取硬核信噪比。
- **反直觉认知（Counter-intuitive Insight）**：如果观点符合所有人预期，等于没说。必须打破常识。

### 2. 表达法则
- **两行打碎认知**：第一句抛出痛点，第二句给出颠覆性结论。
- **第一人称「我」的粗粝真实感**：强调个人痛点（“被折磨了三天”、“自己手搓了一个”），严禁大厂公关腔的「我们」。
- **闭环交付（Thread 运营）**：主推放痛点 + 核心对比图；首条回复（Thread #1）挂载**一行安装命令 + GitHub 链接**。

### 3. 经典结构范式
```text
【主推：痛点打碎】我被 [官方/常见方案] 折磨了整整一周。
【主推：反常识解法】原来根本不需要 [重型框架]，只需手搓一个 100 行的 [核心机制]。
【主推：实测数据对比】冷启动从 800ms 压到 19ms，无常驻进程。
  ↓
【Thread #1：闭环承接】一行运行命令：`curl -s ...` + 开源仓库链接
```

## 四、🐙 GitHub / 开发者社区（客观边界 · 对事不对人 · 证据链）

### 1. 核心受众心理机制
- **确定性与可复现性（Reproducibility）**：开发者最讨厌“不好用”、“卡死了”这种主观情绪词，尊重客观事实与环境上下文。
- **面子威胁最小化**：Issue/PR 讨论极易演变成维护者与提单者的阵营对抗。必须自曝先行、降低防御。

### 2. 表达法则
- **归因于情境**：永远不评价对方的代码能力，将缺陷归因为“特殊边界条件”、“高并发极端场景”。
- **先肯定对方贡献**：提改进建议前，先确认当前架构的合理性与对方的劳动。
- **三段式骨架**：预期行为 vs 实际行为 vs 最小复现路径（Minimal Reproducible Example）。

## 五、📱 微信公众号（沉浸长文 · 故事内核 · 工具结论）

### 1. 核心受众心理机制
- **专注阅读心智**：公众号读者愿意花 5~8 分钟阅读，但必须在开头 30 秒内建立阅读契约（“这篇文章能帮我解决什么 / 带来什么认知增量”）。

### 2. 表达法则
- **工具结论型长文**：直接给开箱即用的 checklist、配置单或架构图，减少文学性抒情。
- **反思型成长长文**：真实记录个人在技术、创作或创业路上的踩坑与蜕变，不卖成功学焦虑，呈现真实的犹豫与决策复盘。
